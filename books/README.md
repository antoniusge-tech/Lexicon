# Книги под группы слов

Скил `/make-book` пишет книгу для раздела Reading из слов выбранных групп, с упражнениями к каждой главе.

1. Скопируйте `inbox/example.txt` в `inbox/<имя>.txt` и заполните параметры.
2. В Claude Code: `/make-book` (обработает все файлы в `inbox/`) или `/make-book books/inbox/<имя>.txt`.
3. Готовая книга появится в `ready/<slug>.mjs`, исходник уйдёт в `done/`.
4. Загрузка: `npm start`, откройте http://localhost:3000 под своим аккаунтом и в консоли браузера выполните
   ```js
   await import('/books/ready/<slug>.mjs')
   ```
   У админа книга публикуется для всех (Reading → Books), у остальных попадает в My texts.

Проверить книгу без загрузки: `node scripts/check-book.mjs books/ready/<slug>.mjs`.

## Параметры

Строки `# ключ: значение` в начале файла, ниже — свободные пожелания к сюжету.

| ключ | по умолчанию | смысл |
|---|---|---|
| `title` | придумает | название книги |
| `lang` | `en` | `en` или `ro` |
| `level` | `B1` | A1…C2 |
| `groups` | обязательно | группы через запятую: «Родитель / Подгруппа», имя подгруппы или родителя целиком |
| `user` | `Yurii` | чьи группы смотреть |
| `chapters` | `auto` | число глав (`auto` ≈ 30 слов на главу) |
| `chapter words` | `400` | длина главы |
| `kind` | `story` | `story`, `stories`, `articles`, `mixed` |
| `exercises` | все | `questions, fill, bank, dialogue` |
| `replace` | `no` | `yes` — перезаписать книгу с тем же названием |

## Упражнения в приложении

После последней страницы главы (или кнопкой **Practice** в шапке ридера):

- **Questions** — вопросы на понимание главы;
- **Fill the gaps** — предложение из главы, нужно вписать пропущенное слово;
- **Word bank** — абзац с пропусками, слова выбираются из набора прямо в текст;
- **Dialogue** — сцена по главе: реплики собеседника звучат вслух, свою реплику нужно произнести, подставив пропущенное слово (или вписать его, если браузер не умеет распознавать речь).

Каждый ответ идёт в XP и дневную цель, а если у вас есть карточка этого слова, то и в её интервальное повторение.

`example.mjs` — образец формата книги на одну главу.
