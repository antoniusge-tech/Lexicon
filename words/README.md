# Списки слов для импорта

- `inbox/` — сюда кладёте сырые списки (`.txt`, один элемент на строку).
- `ready/` — сюда скилл `add-words` пишет готовые файлы для **Import → Load file**.
- `done/` — обработанные исходники переносятся сюда.

Содержимое папок не попадает в git.

## Формат файла в inbox

```text
# lang: en            en или ro (по умолчанию en)
# type: phrases       words / phrases / phrasal verbs / idioms / mixed
# group: Work         необязательно, напоминание, какую группу выбрать в Import
# note: примеры про офис, уровень B1   необязательно, пожелания к примерам

make a decision
bank (берег реки)        ← нужное значение в скобках
get along - ладить       ← свой перевод через дефис
break the ice (идиома)   ← тип для отдельной строки в смешанном списке
```

Строки с `#` — настройки. Пустые строки, нумерация и маркеры не мешают.

## Как запустить

```text
/add-words words/inbox/work-phrases.txt
```

Можно несколько файлов сразу или `/add-words words/inbox` — обработать всё, что там лежит.
