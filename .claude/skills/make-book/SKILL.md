# Книга под группы слов

Пользователь задаёт параметры в файле (`books/inbox/*.txt`, формат в `books/README.md`) или прямо в сообщении. Задача: написать связную книгу, в которой встречаются **все** слова выбранных групп (по возможности), с упражнениями к каждой главе, проверить её скриптом и положить в `books/ready/<slug>.mjs`. Пользователь сам загружает книгу одной строкой в консоли.

Если вызвано без аргументов и в `books/inbox/` нет файлов (кроме `example.txt`), показать краткую подсказку из `books/README.md` и остановиться. Если файлы есть — обработать их все по очереди (кроме `example.txt`).

## 1. Параметры

Строки `# ключ: значение` в начале файла, остальное — свободные пожелания (сюжет, герои, тон, что обязательно показать).

| ключ | по умолчанию | смысл |
|---|---|---|
| `title` | придумать | название книги (английское/румынское, по языку) |
| `lang` | `en` | `en` или `ro` |
| `level` | `B1` | CEFR: грамматика и лексика вне списка — строго по уровню |
| `groups` | — (обязательно) | группы через запятую: полное имя «Родитель / Подгруппа», имя подгруппы или родителя (берутся все его подгруппы) |
| `user` | из памяти (`Yurii`) | логин, от имени которого видны группы |
| `chapters` | `auto` | число глав; `auto` = ceil(слов / 30), но 3–12 |
| `chapter words` | `400` | длина главы в словах (300–600) |
| `kind` | `story` | `story` — одна история с героями; `stories` — отдельные рассказы; `articles` — статьи/письма/документы; `mixed` |
| `exercises` | `questions, fill, bank, dialogue` | какие упражнения делать |
| `replace` | `no` | `yes` — перезаписать книгу с тем же названием (прогресс читателей сохранится) |

## 2. Слова

```bash
node scripts/check-words.mjs --user <user> --lang <lang> --words "<группа1>,<группа2>" > <scratchpad>/words.json
```

Скрипт читает базу через `firebase-admin` и `./service-account.json` (сам файл не открывать). Выдаёт `{ groups, words: [{ word, tr, pos, group }] }`. Если группа не найдена — вывести `--groups` и спросить пользователя. Если скрипт не запускается — сказать почему и попросить список слов.

Целевые слова (`targets`) — поле `word` как есть. Дубли схлопнуть.

## 3. План (в scratchpad, не в репозиторий)

- Сюжет на все главы: завязка, развитие, развязка; у глав — короткие названия.
- Распределить слова по главам по смыслу (HR: найм → собеседование → онбординг → …). Каждое слово хотя бы в одной главе; 20–30% самых важных — в 2–3 главах (повторение важнее разового упоминания).
- 25–40 целевых слов на главу 400 слов. Если слов слишком много для `chapters` — увеличить число глав и сказать об этом.

## 4. Текст глав

- Естественный, интересный текст уровня `level`: живые герои, диалоги, конкретные детали. Не «учебник», не перечисление слов.
- Целевое слово — **в том значении, что в карточке** (`tr`), в естественной коллокации. Формы можно менять (hire → hired), но для проверки лучше хотя бы раз дать слово в форме, совпадающей по основе (неправильные формы — took для take — скрипт не узнает).
- Фразы и фразовые глаголы — подряд, не разрывая (`take on a new employee`, не `take a new employee on`), иначе скрипт их не найдёт.
- Никакой разметки в тексте: ни `[[…]]`, ни `**`, ни кавычек вокруг целевых слов.
- Абзацы разделяются пустой строкой; абзац 40–120 слов. Прямая речь — обычными кавычками “…”.
- Не использовать символ `` ` `` (текст лежит в шаблонной строке JS).

## 5. Упражнения к каждой главе (`exercises`)

Разметка пропуска — `[[слово]]`, ровно так, как оно стоит в предложении (с формой).

- `questions` — 3–5 вопросов на понимание сюжета главы (не на перевод слов): `{ q, options: [4 варианта], answer: индекс верного 0–3, why: короткое пояснение по-русски }`. Неверные варианты правдоподобные, примерно той же длины. Верный — в разных позициях (порядок всё равно перемешивается в приложении).
- `fill` — 5–8 предложений **дословно из главы**, в каждом ровно один `[[пропуск]]` на целевом слове: `{ s: 'They decided to [[hire]] two developers.', hint: 'нанимать' }`. `hint` — перевод слова (из `tr`), без самого слова.
- `bank` — один абзац **дословно из главы**, 4–7 пропусков на разных целевых словах (одинаковых пропусков не бывает) + 2–3 лишних слова-отвлекателя той же части речи: `{ text: '…[[slovo]]…', extra: ['…', '…'] }`.
- `dialogue` — короткая сцена по мотивам главы (6–10 реплик, 2–3 персонажа): `{ title, you: 'Имя роли ученика', lines: [{ who, text, tr }] }`. Реплики роли `you` (3–5 штук) содержат ровно один `[[пропуск]]` на целевом слове; реплики остальных — без разметки. `tr` — перевод реплики на русский. Реплики короткие (до ~15 слов), их произносят вслух.

## 6. Файл книги

`books/ready/<slug>.mjs` (slug — название в kebab-case). Формат — как `books/example.mjs`:

```js
/* <Title> — written by the make-book skill from books/inbox/<file>.txt (<groups>).
   Upload: npm start, open http://localhost:3000 signed in, then in the console:
     await import('/books/ready/<slug>.mjs') */
import { uploadBook } from '../../scripts/upload-book.mjs';

export const BOOK = {
  title: '…', author: 'Lexicon', level: 'B1', lang: 'en', replace: false,
  targets: [ /* все целевые слова */ ],
  chapters: [
    { title: '…', text: `…`, exercises: { questions: [...], fill: [...], bank: {...}, dialogue: {...} } },
  ],
};

export default await uploadBook(BOOK);
```

Большую книгу писать по главам (Write первой части, затем Edit с добавлением глав), чтобы не упереться в размер одного вызова.

## 7. Проверка

```bash
node scripts/check-book.mjs books/ready/<slug>.mjs
```

Показывает покрытие (`targets`, найденных теми же функциями, что подсветка в ридере), слова, которых нет, слова, встреченные один раз, и ошибки в упражнениях.

- Ошибки — исправить все.
- «Не найдены» — для каждого: если слово есть в неправильной форме (took) — оставить, но назвать в отчёте; если его правда нет — вписать в подходящую главу (или добавить абзац) и перепроверить. Цель — 100%, минимум 95%.
- Предупреждения «предложения нет в тексте главы дословно» — поправить упражнение, а не текст.

Повторять, пока ошибок нет и покрытие в норме.

## 8. Завершение

- Исходный файл параметров перенести в `books/done/` (`mv`). `example.txt` не трогать.
- Ответ пользователю: название, уровень, главы (названия), слов в книге, покрытие X из Y, что не найдено и почему, ссылка на файл, и как загрузить:
  1. `npm start`, открыть http://localhost:3000 под админом (тогда книга общая, в Reading → Books; у не-админа — в My texts);
  2. в консоли браузера: `await import('/books/ready/<slug>.mjs')`.
- Если книга с таким названием уже есть, загрузка её пропустит — для перезаписи поставить `replace: true` в файле книги.
