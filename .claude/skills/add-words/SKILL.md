# Добавление слов в Lexicon

Пользователь присылает список (слова, фразы, словосочетания — что именно, он уточняет сам) и, возможно, язык и группу. Задача: проверить, каких из них ещё нет, и выдать готовый текст для вставки в экран **Import**.

Если вызвано без аргументов и без списка — показать пользователю краткую подсказку из `words/README.md` (формат файла и команду запуска) и остановиться.

## 0. Источник: текст или файлы

- **Список прямо в сообщении** — работать с ним, результат выдать блоком в ответе (шаг 4).
- **Путь к файлу или папке** (обычно `words/inbox/…`; папка = все `.txt` в ней) — режим файлов, формат описан в `words/README.md`:
  - Строки, начинающиеся с `#`, — настройки `# lang:`, `# type:`, `# group:`, `# note:`; они важнее значений по умолчанию. `note` — пожелания к примерам.
  - Каждый файл обрабатывается отдельно со своими настройками. Дубли проверяются и по базе, и между файлами одного запуска.
  - Результат записать в `words/ready/<имя-исходника>.txt` (если больше 100 строк — `<имя>-1.txt`, `<имя>-2.txt`, … по 100). Внутри только строки импорта, без комментариев: файл загружается кнопкой **Load file** на экране Import.
  - Исходник перенести в `words/done/` (`mv`), чтобы он не обработался повторно. `example.txt` — образец, его не трогать и не обрабатывать, если пользователь не попросил.
  - В ответе блок с текстом не печатать — дать ссылки на файлы в `ready/`, сводку и пропущенные.

## 1. Разобрать вход

- Язык: `en` (по умолчанию) или `ro`, если пользователь сказал «румынский» или слова явно румынские.
- Тип: **word** (одно слово), **phrase** (словосочетание/коллокация, напр. `make a decision`), **phrasal verb**, **idiom**. Если пользователь указал тип — следовать ему; это влияет на `pos` и на пример.
- По одному элементу на строку. Убрать нумерацию, маркеры, лишние пробелы; дубли внутри самого списка схлопнуть.
- Регистр: строчные, заглавная только у имён собственных.
- Глаголы — без частицы: `decide`, не `to decide`; румынские — голый инфинитив (`merge`, не `a merge`).
- Если пользователь дал слово уже с переводом (`word - перевод`) — взять его перевод, остальное дополнить.
- Уточнение в скобках (`bank (берег реки)`, `break the ice (идиома)`) — это значение или тип, в само слово его не включать.

## 2. Проверить дубликаты

Запросить у пользователя логин в приложении, если он ещё не известен (из памяти или этого разговора), затем:

```bash
printf '%s\n' "word1" "word2" ... | node scripts/check-words.mjs --user <username> --lang <en|ro>
```

Для файлов — сначала очищенные слова (без `#`-строк, скобок и переводов) собрать во временный файл в scratchpad и подать его на stdin.

Скрипт читает базу через `firebase-admin` и `./service-account.json` (сам файл не открывать) и сравнивает со словами, которые пользователь видит в приложении: свои + общие (`shared`) на этом языке. Для каждого кандидата `status`:

- `exists` — такое слово уже есть → **не включать**, показать, в какой группе.
- `similar` — та же основа (другая форма, диакритика, `to`/артикль) → показать найденное и решить по смыслу: та же лексема — пропустить; другая (напр. `close` прил. vs `closes`) — включить и сказать об этом.
- `new` — включать.

`--groups` выводит листовые группы пользователя — пригодится, если он спросит, в какую группу класть.

Если скрипт не запустился (нет ключа, нет сети, запрещено правами) — сказать об этом и предложить альтернативу: пользователь экспортирует/вставляет список своих слов, или проверка пропускается с явным предупреждением.

## 3. Заполнить поля

Для каждого нового элемента — одна строка:

```
word | ipa | tr | example | exampleTr | pos
```

- `ipa` — IPA в косых чертах, британский вариант для английского: `/ˈdʒɜː.ni/`. Для фраз — транскрипция всей фразы. Для румынского поле **оставить пустым** (`word || tr | ...`): приложение само строит транскрипцию по правилам (`lwRoIpa`).
- `tr` — краткий русский перевод, 1–3 варианта через запятую (как в Cambridge Dictionary); пояснение в скобках при необходимости.
- `example` — короткое естественное предложение уровня B1–B2, где элемент употреблён именно в этом значении; для фразы — фраза целиком.
- `exampleTr` — перевод примера на русский.
- `pos` — строго одно из: `noun, verb, adjective, adverb, phrasal verb, phrase, idiom, other`. Коллокации и устойчивые сочетания — `phrase`.
- **Символ `|` внутри полей запрещён** — он разделитель. Не использовать его ни в переводе, ни в примере.
- Многозначное слово: одна карточка на основное значение; если пользователь явно хочет несколько значений — отдельные строки с уточнением в скобках в `tr`.

## 4. Ответ пользователю

1. Короткая сводка: сколько всего, сколько новых, сколько пропущено как дубликаты.
2. Пропущенные — списком: `слово → уже есть в «Группа»` (и `similar`-решения с причиной).
3. Готовый текст — в одном блоке ```text без лишних комментариев внутри, чтобы его можно было скопировать целиком в Import.
4. Напомнить выбрать группу на экране Import (если пользователь назвал группу — назвать её).

Если список больше ~100 строк, разбить на блоки по 100.

Пример строки (en): `make a decision | /meɪk ə dɪˈsɪʒ.ən/ | принять решение | We need to make a decision by Friday. | Нам нужно принять решение до пятницы. | phrase`
Пример строки (ro): `lua o decizie || принять решение | Trebuie să luăm o decizie până vineri. | Нам нужно принять решение до пятницы. | phrase`
